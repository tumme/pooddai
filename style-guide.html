05 · ส่งออก

ก๊อปไปใช้ต่อ

JSON ด้านล่างเป็นรูปแบบของปลั๊กอิน Tokens Studio โดยเฉพาะ แยกเป็นสามชุด — core (สีแบรนด์ สีบอกผล ตัวอักษร ความมน) กับ light และ dark ที่สลับกันตามโหมด ไฟล์เดียวกันนี้อยู่ที่ docs/pooddai-tokens.json เลือกอัปโหลดไฟล์แทนการก๊อปได้

นำเข้า Figma ยังไง

1 · ติดตั้งปลั๊กอินเปิดไฟล์ Figma → เมนู Plugins → หา Tokens Studio for Figma
2 · นำเข้าไฟล์ในปลั๊กอิน กด Tools → Load from file/folder แล้วเลือก pooddai-tokens.json
3 · ติดตั้งฟอนต์ก่อนต้องมี IBM Plex Sans Thai ในเครื่อง ไม่งั้น Text Style จะตกไปใช้ฟอนต์อื่นเงียบๆ
4 · สร้างสไตล์กด Export → เลือก Styles จะได้ Color Style กับ Text Style ครบทุกตัว
5 · สลับโหมดแท็บ Themes มี Light กับ Dark ให้สลับ ทุกโทเคนเปลี่ยนตามทั้งไฟล์
